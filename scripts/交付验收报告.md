# DMS 文档管理系统 — 交付验收报告

> 部署环境：Debian 13.5 (dms.example.internal) | 访问地址：http://dms.example.internal/
> 版本：DMS-v1.0 | 完成日期：2026-09-09

---

## 一、系统架构（组合方案落地）

| 层 | 选型 | 状态 |
|---|---|---|
| 后端 | RuoYi-Vue-Plus 6.0（Spring Boot 4.1 / JDK 21） | ✅ |
| 数据库 | PostgreSQL 17（RuoYi sys_* + doc 7 表 + tsvector/pg_trgm） | ✅ |
| 缓存 | Redis 8.0 | ✅ |
| 对象存储 | MinIO（dms-files 桶） | ✅ |
| 文档处理 | Apache Tika 2.9.1 + LibreOffice 25.2 | ✅ |
| 上传 | tus 协议（tus-java-server）+ Uppy 3 | ✅ |
| 前端 | Vue3 + Element Plus + Vite（自研 Windows 风格界面） | ✅ |
| 反代 | Nginx 1.26（80 端口） | ✅ |

## 二、功能验收清单

### 系统管理（复用 RuoYi）
- [x] 用户管理：列表/搜索/新增/编辑/删除/启停/重置密码（真实 API）
- [x] 角色管理：列表/新增/编辑/删除
- [x] 部门管理：树表/新增/编辑/删除
- [x] 系统参数：列表/搜索/编辑

### 文档管理核心
- [x] 登录认证（JWT，admin/admin123）
- [x] 我的文档（默认首页）Windows 风格
- [x] 资料库公共目录
- [x] 文件夹：树形无限层级/创建/重命名/删除/移动/物化路径
- [x] 文件：上传(tus 断点续传)/列表/下载(Range)/删除/移动/复制/剪切粘贴
- [x] 预览：PDF(PDF.js)、图片、文本、Office→PDF(LibreOffice 自动转)
- [x] 文本提取：Tika → doc_file_text（全文搜索数据源）
- [x] 搜索：文件名+内容（中英文 ILIKE）
- [x] 回收站：软删除/恢复/永久删除/清空
- [x] 权限：user/role/dept × 8 权限位、继承、所有者完全控制、**越权拦截验证**
- [x] 快捷键：F2/Delete/Ctrl+A/Enter
- [x] 右键菜单、多选、拖拽移动到文件夹树
